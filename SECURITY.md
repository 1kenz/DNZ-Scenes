# Security policy

DNZ-Scenes is a local macOS menu bar app: no network access, no telemetry, no third-party dependencies.
It needs the Accessibility permission to move windows (nothing else; no Screen Recording, no Input Monitoring).

**Reporting a vulnerability:** please open a private report through the repository's
*Security > Report a vulnerability* page (GitHub private vulnerability reporting) instead of a public issue.
Expect a first answer within a few days; this is a personal project maintained on a best-effort basis.

Only grant Accessibility to a build you compiled yourself or trust. See `docs/security-review.md` for the review of v0.3.0.
