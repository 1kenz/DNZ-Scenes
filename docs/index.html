One hotkey. Three screens. One profile.

DNZ-Scenes is a macOS menu bar app that switches your whole multi-monitor setup between named profiles. Each profile pins apps to screens, changes the wallpaper and has its own shortcut.

Get it on GitHub Build from source

What it does

Named profiles

Up to 20 profiles with a colour and a wallpaper each. Rename, add and delete them in the built-in editor.

Apps pinned to screens

Assign apps to the left, right or laptop display. Switching tiles the windows; one click captures your current layout.

Profile ring

Press one shortcut and a radial picker opens at the mouse pointer. Click a profile and all screens follow.

Made for Logitech MX

Every action is a plain keystroke, so any MX button mapped in Logi Options+ can switch profiles.

Private by design

No network, no telemetry, no dependencies. Only the Accessibility permission is needed.

Scriptable

A URL scheme lets Shortcuts and scripts switch profiles: dnzscenes://switch/003.

The profile ring

Bind ctrl opt Space to a mouse button. A circle with your profiles opens under the pointer; click one, or press 1 to 8. Esc or a click outside closes it.

Install

DNZ-Scenes is built from source (Xcode or the Swift toolchain, macOS 13 or newer).

git clone https://github.com/<your-user>/DNZ-Scenes.git
cd DNZ-Scenes
./scripts/build-app.sh
open build/DNZ-Scenes.app

On first launch, grant Accessibility in System Settings > Privacy & Security. That is the only permission the app needs.

Good to know

This is an early-stage personal project. It does not use native macOS Spaces (there is no public API); it manages its own virtual workspaces with the Accessibility API. Native full-screen apps are not handled, and the app is not sandboxed, so it is not meant for the Mac App Store.
